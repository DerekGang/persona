## Native routes

- iOS groups Agents by repository. HarmonyOS opens the project tree from Projects. [Project tree](pages/projects-light.png)
- Both fold the release terminal tab in the weather tree. [Collapse a terminal tab](pages/release-collapsed-light.png)
- iOS reveals search in the repository list. HarmonyOS uses the project search field. [Search projects and sessions](pages/project-search-light.png)
- iOS expands weather in the project tree. On HarmonyOS, the project menu opens the dedicated weather repository page and its worktree list. [Repository details](pages/project-light.png)
- iOS opens the weather space from a conversation. HarmonyOS opens the worktree from Projects. Both show a two-column agent grid at the default type size. [Worktree details](pages/worktree-light.png)
- The iOS New Chat form corresponds to HarmonyOS New Agent. [New agent](pages/new-agent-light.png)
- Both open the directory picker from the start form. The current directory may differ. [Choose a working directory](pages/folder-browser-light.png)
- Each screenshot shows the configured form before submission. See each capture for its selected values. [Agent ready to start](pages/start-ready-light.png)
- Both clients expand the input card into a larger editor and return to the same draft. HarmonyOS also verified the English dictation fallback to the system keyboard, with the draft still editable. [Focused composer](pages/composer-light.png)
- Both open this tool from the PR #42 conversation and retain its title and sibling tabs. [Workspace files](pages/files-light.png)
- Both open this tool from the PR #42 conversation and retain its title and sibling tabs. [Git workspace](pages/git-light.png)
- iOS opens MacBook from the machine directory. HarmonyOS opens the same fixture machine from its overview. [Machine details](pages/machine-detail-light.png)
- Both inspect six hours of CPU history for the fixture MacBook. Each capture has its own sampling time and values. [Machine metrics](pages/machine-monitor-light.png)
- Both list the app languages. Below them, iOS shows Automatic for dictation and HarmonyOS identifies the system input method. [Language settings](pages/language-light.png)
- iOS opens Agent preferences through settings search. HarmonyOS opens them from its Agent settings entry. [Agent preferences](pages/agent-preferences-light.png)
- Both apps use the repository’s synthetic meeting data. [Meetings](pages/meetings-light.png)
- Both open the synthetic Mobile Experience Review meeting. [Meeting details](pages/meeting-detail-light.png)
