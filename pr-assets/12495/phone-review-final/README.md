- Open Language in Settings. Automatic dictation follows the conversation language and the device’s available input methods. [Language settings](pages/language-light.png)
- Open Agent preferences from Settings search and return to the same query. [Agent preferences](pages/agent-preferences-light.png)
- Compare the same projects across Focus, Other Active and Completed, including priority and state. [Knowledge](pages/knowledge-light.png)
- Compare the meeting and note setup, calendar naming, assistant invitation and start action. [Meetings](pages/meetings-light.png)
- Open the Mobile Experience Review recording and inspect its tags and confirmed facts. [Meeting details](pages/meeting-detail-light.png)
